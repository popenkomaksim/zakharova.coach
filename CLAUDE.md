# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A marketing/landing site for a trail-running/ski-mountaineering coach, built with Create React App and i18next (Ukrainian, English, Polish, Swedish, Finnish, Italian, French). There is no backend — pricing, race/event data, and content are static JS/JSON, plus one embedded Google Calendar iframe.

## Git

Never run `git commit` (or anything that creates a commit, e.g. `git rebase --continue`) unless the user explicitly asks for a commit in that turn. Leave changes staged/unstaged for review instead.

## Commands

- `npm start` — run dev server (CRA, localhost:3000)
- `npm run build` — production build to `build/`, then copies `build/index.html` to `build/404.html` **and** to an `index.html` under a dedicated directory for every client-side route (`formats`, `prices`, `additional-services`, `skitour-chechlist`, `calendar`, `about`, `achievements`, `contact`, `privacy`, `races`) — all needed so GitHub Pages serves a working page on a hard refresh/direct link to any route. When adding a new top-level route in `src/index.js`, add its directory to this `build` script too.
- `npm test` — CRA/Jest test runner in watch mode; pass a file/name pattern as an extra arg to scope it (e.g. `npm test -- App.test`), or `CI=true npm test` for a single non-watch run
- `npm run deploy` — publishes `build/` to GitHub Pages via `gh-pages` (runs `predeploy`/`build` first)
- Linting (config in `.eslintrc`, extends `airbnb` + `prettier`) runs via CRA's internal `eslint-webpack-plugin` during `npm start` / `npm run build` — there's no root babel config, so a bare `npx eslint src` fails on every file with a JSX parsing error; don't use it standalone

## Architecture

- **Routing**: `src/index.js` sets up a `react-router-dom` `createBrowserRouter`. `App.js` (the landing page) is mounted at multiple paths — `/`, `/formats`, `/races`, `/prices`, `/additional-services` — and on load scrolls to the matching `#section-id` (see the `useEffect` in `App.js` keyed off `pathname`); these aren't separate pages, they're deep links into the one-page layout. Separate standalone pages: `/skitour-chechlist` (`SkiTourList.js`), `/calendar` (`Calendar.js`), `/about` (`About.js`), `/achievements` (mounts `sections/AchievementsSection.js` directly with an `onBack` that navigates home), `/contact` (`Contact.js`), `/privacy` (`Privacy.js`). Every page shares `components/Header.js` and most wrap content in `components/PageShell.js`.
- **`App.js`** is a thin orchestrator: it wires `useContactRedirects`/`useExchangeRate` (in `src/hooks/`) and composes the landing page purely from section components in `src/sections/` (`HeroBanner`, `HeroSection`, `RacesSection`, `FormatsSection`, `PatrioticBanner`, `PricingSection`, `ExtraServicesSection`, `TestimonialsSection`, `PartnersSection`, `ClosingSection`), each wrapped in `components/ScrollReveal.js` for scroll-triggered fade-in. New sections should be added as their own component under `src/sections/` and slotted into `App.js`, not inlined there. Retired sections/hooks/components should be deleted outright rather than archived — rely on git history to recover them if ever needed.
- **`FormatsSection`/`FormatCard`**: the "Формати співпраці" section is a list of `FormatCard` entries (title, description, optional photo, pagination label like `"01/05"`, `imageSide`) — add a new cooperation format by adding another `<FormatCard>` rather than hand-rolling markup.
- **Races**: `RacesSection.js` renders a static, hardcoded `races` array (name, href, logo path) of events the coach is affiliated with/promotes — there's no external data source or "upcoming events" feed; add/remove a race by editing that array. `Calendar.js` (`/calendar`) is unrelated — it just embeds a public Google Calendar via `<iframe>`.
- **Pricing**: EUR prices are hardcoded per plan/service in `PricingSection.js`/`ExtraServicesSection.js` and converted to UAH via `src/convert.js`'s `convert(eur, rate)`. The rate itself is live: `useExchangeRate.js` fetches the current EUR rate from the NBU (`bank.gov.ua`) API on mount, applies a `MARKUP` multiplier from `convert.js`, and falls back to `convert.js`'s `FALLBACK_RATE_EUR_TO_UAH` constant if the fetch fails — update that constant occasionally so the fallback doesn't drift too far from reality, but it's not the source of truth for normal operation.
- **i18n**: `src/i18n/index.js` configures `i18next` with `react-i18next` and `i18next-browser-languagedetector` (query string `?lang=`, then `localStorage`, then browser). Translation strings live in `src/i18n/locales/{uk,en,pl,sv,fi,it,fr}.json` — `uk` is the `fallbackLng`. It also updates `document.title`/meta description and `<html lang>` on language change. When adding user-facing copy, add the key to **all** locale files, not just `uk.json`.
- **Contact/conversion actions**: `useContactRedirects` (`src/hooks/useContactRedirects.js`) exposes `redirectToTelegram`/`redirectToWhatsup`, which fire Google Ads conversion events via the global `gtag` (loaded outside the bundle, hence the `eslint-disable` on those calls) before redirecting to `t.me` / `wa.me` links. Reuse this hook rather than adding new ad-hoc redirect logic.
- **Styling**: mix of `styled-components` (for one-off styled icons/wrappers) and inline `style={}` props on Ant Design (`antd`) components — there is no CSS module/Tailwind system. `App.css` / `index.css` hold minimal global styles. `@fontsource/montserrat` is imported directly in components that need the font loaded. ESLint (`styled-components-varname` plugin) requires every styled-components variable name to start with `Styled`. Responsive breakpoints are hand-rolled media queries (commonly `≤575.98px` for mobile, `≥992px` for desktop nav) rather than a shared theme/breakpoint system.
- **Media assets**: large `.mp4`/`.mov`/`.gif` files live directly under `src/` and are imported like modules (e.g. `import PolinaRun from "./polina_run.mp4"`) so CRA/webpack fingerprints them; static images referenced by plain string path (e.g. `./polina.jpg`) instead live in `public/`. Below-the-fold images should get `loading="lazy"`; autoplaying video should use `preload="none"` plus an `IntersectionObserver` to start/stop playback near the viewport (see `LoopVideo.js`) rather than eagerly loading — mobile data/battery cost was a deliberate fix, don't regress it.
- **Deployment**: static GitHub Pages site behind a custom domain (`CNAME` = `zakharova.coach`), with `.nojekyll` to prevent Jekyll processing. `homepage` in `package.json` and the router `basename: "/"` assume the site is served from the domain root.
- **Testing**: `npm test` needs two non-obvious fixes already in place — `package.json`'s `overrides.@babel/core` (keeps the transitive Babel version consistent) and `jest.transformIgnorePatterns` (lets Jest transform axios's ESM entry); and `setupTests.js` shims `window.matchMedia`, which JSDOM lacks but antd's responsive `Row`/`Col` needs.
- **`tools/contour-map-generator`**: a standalone helper script/tool (not part of the CRA build or `src/`) — treat it as separate tooling, not app code.
